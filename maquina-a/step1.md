# Diagnóstico e Manutenção

A estação Linux encontra-se disponível para manutenção.

Utilize o terminal para investigar o problema descrito na Ordem de Serviço.

Você deverá:

- identificar a causa da falha;
- realizar a correção necessária;
- verificar se o serviço voltou a funcionar;
- estar preparado para explicar o procedimento utilizado.

Quando considerar que a manutenção foi concluída, clique em **CHECK**.

> O sistema somente considerará a manutenção concluída se o problema tiver sido efetivamente corrigido.
