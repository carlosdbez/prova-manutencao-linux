# Prova Prática — Manutenção de Computadores

## Ordem de Serviço — Máquina A

Você é o técnico responsável pela manutenção de uma estação de trabalho Linux utilizada no Laboratório de Automação.

O usuário informou que o computador apresentou uma falha após uma intervenção realizada anteriormente no sistema.

O sistema operacional inicializa, porém um dos serviços utilizados pelo laboratório não está funcionando corretamente.

O serviço responsável pela aplicação é:

`laboratorio.service`

## Sua missão

Você deverá:

1. Investigar o estado atual do sistema.
2. Identificar o serviço que apresenta falha.
3. Diagnosticar a **causa raiz** do problema.
4. Realizar a manutenção necessária.
5. Reiniciar o serviço, se necessário.
6. Demonstrar que o sistema voltou a funcionar corretamente.

## Regras

- Não reinstale o sistema operacional.
- Não remova o serviço `laboratorio.service`.
- Não substitua o serviço por outro.
- Você pode utilizar os comandos e ferramentas disponíveis no Linux.
- Ao terminar, utilize a opção **CHECK** para verificar se o reparo foi realizado corretamente.

> Atenção: fazer o serviço funcionar é apenas parte da atividade. Você deverá ser capaz de explicar ao professor qual era o defeito, como realizou o diagnóstico e qual procedimento utilizou para corrigi-lo.
